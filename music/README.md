# Музыка к видео (3:45)

`intrigue_track.mp3`: интригующий кинематографичный трек, ре минор, 96 BPM, 320 kbps, ровно 3:45.
Сгенерирован кодом (`generate_track.py`), без сэмплов, поэтому проблем с авторскими правами нет.

![waveform](waveform.png)

## Карта трека (под монтаж)

| Время | Секция | Что происходит |
|---|---|---|
| 0:00–0:20 | Интро | Удар, тёмный дрон, тиканье часов, тихий мотив пианино |
| 0:20–0:40 | Напряжение | Сердцебиение, пульсирующий бас, появляется арпеджио |
| 0:40–1:00 | Нарастание 1 | Бочка, хэты, райзер, ускоряющаяся дробь, пауза |
| **1:00** | **Дроп 1** | Удар + «брэм», полный бит, бас, арпеджио |
| **1:40–2:00** | **Провал** | Всё уходит, остаются пианино, тиканье и дрон |
| 2:00–2:20 | Нарастание 2 | Сердцебиение, райзер, дробь |
| **2:20** | **Дроп 2** | Самая мощная часть, лид-мелодия, брэмы |
| **3:00–3:05** | **Стоп** | Резкий обрыв: удар и тиканье часов |
| 3:05–3:35 | Кульминация | Всё на максимуме |
| **3:35–3:45** | Аутро | Финальный удар, затухающие тики |

Ключевые акценты (удобно ставить на них склейки и B-roll): 1:00, 1:20, 1:40, 2:20, 2:40, 3:00, 3:05, 3:35.
Сильная доля бита приходится на каждые 0.625 с, такт длится 2.5 с.

## Пересборка

```bash
python3 generate_track.py track.wav          # нужен только numpy
ffmpeg -i track.wav -b:a 320k intrigue_track.mp3
```

# Трек 2: `warm_track.mp3`, в стиле референса (3:45)

Тёплая эмоциональная мелодичная электроника по мотивам «Everything Works Out In The End» (Luke Willies).
Мелодия и аранжировка оригинальные, сэмплы референса не использованы. Общие с референсом только стиль, тональность и гармония.

- **128 BPM**, бит в половинном темпе (кик на 1 и «2¾», клэп на 3), такт 1.875 с
- **Си-бемоль минор**, гармония Bbm – Db – Fm – Eb, каждый аккорд звучит 2 такта
- Протяжный саб-бас с глайдами и провалом перед каждым новым кругом, широкие аккорды с «пампингом», колокольная мелодия с эхо
- Громкость в полных частях близка к референсу (около −7 dB RMS)

![waveform](warm_waveform.png)

| Время | Секция |
|---|---|
| 0:00 | Интро: пэд и колокольчики |
| 0:15 | Куплет: саб-бас, хэты, щелчки |
| **0:45** | **Дроп 1**: полный бит, аккорды, лид |
| 1:15 | Провал: пэд и мелодия |
| 1:30 | Нарастание: райзер, дробь |
| **1:45** | **Дроп 2** со второй мелодией |
| 2:30 | Тихая часть |
| **2:45** | **Кульминация** |
| 3:30 | Аутро, затухание до 3:45 |

Пересборка: `python3 generate_warm_track.py warm.wav && ffmpeg -i warm.wav -b:a 320k warm_track.mp3`
